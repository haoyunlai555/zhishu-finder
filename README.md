# 质数寻找器 (Prime Number Finder)

一个用 Python 编写的质数查找工具，能够持续搜索并记录质数到文件中。

## 功能特点

- 从指定起始数字开始持续搜索质数
- 使用试除法（优化至 √n）进行质数判定
- 支持按 `Ctrl+C` 优雅停止，确保数据不丢失
- 自动将结果写入 `质数.txt` 文件
- 带缓冲区机制，每 100 个质数刷盘一次，兼顾性能与安全

## 使用方法

```bash
python zhishu.py
```

程序运行后会从第 1,491,556 个质数（起始值 23,735,557）开始继续搜索，并将找到的质数逐条写入 `质数.txt`。

按下 `Ctrl+C` 可随时停止程序，退出时会自动保存缓冲区中未写入的数据。

## 输出示例

```
第 1491556 个质数： 23735557
第 1491557 个质数： 23735569
第 1491558 个质数： 23735587
...
```

## 参数说明

可在脚本顶部修改变量以自定义起始点：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `a` | `1491556` | 质数计数器（当前是第几个质数） |
| `num` | `23735557` | 起始搜索数字 |
